Blob Android accessibility demonstration

Version 0.1.6. This recording uses an isolated Android review installation with the same app-gating code and disclosure as the release build.

  1. Blob opens on the device and shows the prominent disclosure. The user declines, reopens the disclosure, and then gives affirmative consent.
  2. The user enables Blob in Android Accessibility settings and accepts Android’s permission dialog.
  3. Opening the selected Clock app shows Blob’s math gate.
  4. A correct answer grants a temporary pass.

The gate observes the foreground app’s package identifier. It does not read screen contents, type, or click controls in other apps. Selected-app hashes and gate interactions are sent to PostHog for analytics, as described in the disclosure.
